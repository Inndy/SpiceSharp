# 0010. `mouse_mode` is u16 on the wire

- Status: Accepted
- Date: 2026-10-29
- Decided by: agent (spec silent), reviewed by Codex

- **Context:** some docs describe `SpiceMsgMainInit.current_mouse_mode` as u32.
- **Decision:** follow `spice.proto` (`flags16`) for MOUSE_MODE and MAIN_INIT fields as generated by spice-common.
- **Reason:** matches what QEMU actually sends; verified against Proxmox.
