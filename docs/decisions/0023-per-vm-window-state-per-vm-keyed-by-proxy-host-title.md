# 0023. Per-VM window state: per VM, keyed by proxy/host + title

- Status: Accepted
- Date: 2026-10-29
- Decided by: the human

- **Context:** the draft asked whether window size and position are remembered per VM, and keyed by what. The human chose per VM, with a proper preference store instead of the registry (2026-10-29).
- **Decision:** the key is `"<proxy host, or host without a proxy>|<title>"` from the .vv, with the host lower-cased (DNS names are case-insensitive) and the key capped at 512 characters. A .vv without a title remembers nothing: ports and tickets change per session, and with a proxy `host` is an opaque per-session token. Each entry holds the normal (restored) window rectangle in screen pixels, the DPI of its monitor, maximized, full screen, scaling and the last-used time (UTC); at most 200 entries, the least recently used dropped. Capture happens once at close with `GetWindowPlacement` (in full screen, the placement saved on entering it), so maximized and full-screen windows keep their normal rectangle; `rcNormalPosition` is in workspace coordinates and is converted to screen pixels with its monitor's work-area offset. A window that left full screen because the session ended or the display failed is still remembered as full screen. Nothing is saved for a window that never showed a guest frame (an expired ticket doesn't create an entry). At startup the rectangle is used only if `MonitorFromRect(MONITOR_DEFAULTTONULL)` finds a monitor; its size is scaled when that monitor's DPI (`GetDpiForMonitor`) differs from the stored one, keeping the top-left. The window is created there (maximized if remembered); the first guest frame then doesn't center or resize it, except in 1:1, which still takes the guest size in place; full screen is entered at the first frame, like `fullscreen=1`. With "Resize guest with window" the guest follows the restored size through the usual request. Scaling chosen in the menu is stored in this VM's entry and also becomes the default for VMs without one.
- **Reason:** the most stable identity a Proxmox .vv carries (`VM 101 ('name')` plus the pveproxy host); everything else changes per session.
